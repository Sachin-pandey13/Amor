# AMOR

AMOR is an adaptive, personalized, privacy-first AI agent.

## Vision

AMOR aims to combine:

- General-purpose neural reasoning
- Adaptive cognitive routing
- Personal AI memory
- Continual learning
- Preference learning
- Reinforcement learning
- Tool use
- Verification
- Privacy and encryption
- Secure device interaction
- Portable deployment

## Core Research Areas

1. Foundation Brain
2. Personal AI State
3. Continual Learning
4. Preference / Reinforcement Learning
5. Verification
6. Security, Privacy and Forgetting
7. Tool and Device Interaction
